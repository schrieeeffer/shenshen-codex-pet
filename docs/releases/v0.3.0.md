# 深深桌宠 v0.3.0

这一版把“可运行桌宠”扩展为三个入口：Windows 独立版、ChatGPT/Codex 桌面与 CLI、自定义 ChatGPT Web Pet。

## 新增内容

- `Shenshen-ChatGPT-Web-Pet.webp`：符合 `1536×1872`、透明、20 MiB 以下的 Web 上传要求；
- `Shenshen-Codex-Pet.zip` 同时支持桌面端与兼容的 Codex CLI；
- 每个 Release 附带 `SHA256SUMS.txt`；
- 调整 Windows 单文件打包，30 秒本机冒烟测试私有内存从约 216 MiB 降至约 143 MiB；
- 修复部分 Windows PowerShell 5 环境中 Codex 安装脚本的中文编码解析失败；
- README 增加安全/隐私卡、SmartScreen 原因、完整卸载方法；
- 新增角色来源与许可链记录，并明确区分一手证据、媒体报道和未证实推断。

## 下载建议

- 只想双击运行：下载 `ShenshenPet-Windows-x64.zip`；
- 想在 ChatGPT/Codex 桌面或 CLI 使用：下载 `Shenshen-Codex-Pet.zip`；
- 想在 ChatGPT Web 使用：直接下载并上传 `Shenshen-ChatGPT-Web-Pet.webp`。

Windows EXE 暂无商业代码签名，首次运行仍可能出现 SmartScreen 信誉提示。请确认下载源并用 `SHA256SUMS.txt` 校验文件。
