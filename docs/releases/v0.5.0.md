# 深深桌宠 v0.5.0

v0.5.0 把原计划的 v0.4 状态桥接与 v0.5 成长/角色包能力合并发布，并将“不影响电脑性能”作为发布门槛。

## 推荐下载

- `ShenshenPet-Windows-x64.zip`：推荐。免安装运行库的自包含绿色版；
- `ShenshenPet-Windows-x64-runtime-shared.zip`：复用已安装的 .NET 10 Desktop Runtime，减少下载与磁盘体积；
- `Shenshen-Codex-Pet.zip`：ChatGPT/Codex 桌面与 CLI Pet；
- `Shenshen-ChatGPT-Web-Pet.webp`：ChatGPT Web 上传文件；
- `Shenshen-Default-Pet-Pack.zip`：可导入 Windows 独立版的默认角色包。

## 新功能

- 节能模式默认启用：10 FPS，减少自动散步，隐藏/暂停后停止渲染；
- 完整 atlas 拆为按需加载帧，常驻缓存最多 12 张；
- 节能模式启用 Windows EcoQoS 与较低进程优先级；
- 原生 Win32 托盘，移除 Windows Forms 和 System.Drawing 常驻依赖；
- 每日白饭、喂食和羁绊等级，全部离线保存在本机；
- Pet Pack 导入会验证路径、文件数量、解压体积、PNG 尺寸和 SHA-256；
- 可选 Codex Hooks 状态桥接：任务开始时工作、等待批准时等待、结束时等待检查；
- Hook 安装会备份并保留用户已有的 `hooks.json`，卸载只删除深深条目。

## 隐私与性能

Windows 独立版仍不联网、不遥测，不需要管理员权限，也不会默认开机启动。Hook 桥接只写 `%LOCALAPPDATA%\ShenshenPet\codex-state.json` 中的动画状态和时间戳，不读取或保存提示词、工具参数和聊天正文。

共享运行库版需要 [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0)。两个 Windows 包均通过发布包自检；本机实测两者常驻内存接近，因此内存优化来自 10 FPS、隐藏停表、按需帧和有界缓存，而不是分发方式。具体数据见 README 的“性能与安全”段落。

最终自包含包在 Windows 11 build 26200、16 逻辑处理器上的 30 秒可见空闲测试约为 116.1 MiB 私有内存、185.5 MiB 工作集、0.36% 整机 CPU；重复测试整机 CPU 为 0.26%。相较 v0.3.0 记录值，私有内存下降约 19%，工作集下降约 17%。通过真实右键菜单隐藏后，20 秒稳定态约为 105.5/170.9 MiB，CPU 增量为 0.00%（当前计时精度）。
